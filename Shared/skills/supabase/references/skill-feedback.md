# Optional maintainer feedback reference

Use only when the user explicitly requests a maintainer feedback draft. A reported product
or Skill defect does not trigger issue creation or load another pack.
Use [the template](../assets/feedback-issue-template.md) with the exact affected reference,
expected behavior and public evidence. Remove credentials and private project data.
Sending any issue/message is a separate external action requiring existing authorization;
prepare the draft first and follow the authorized destination. This reference grants none.
